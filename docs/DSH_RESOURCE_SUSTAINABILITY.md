# 有限地图的资源续航（2026-10-05）

本文件补充 docs/DSH_DEFENSE_SURVIVAL_DESIGN.md，是同一轮必须完成的内容。DSH 全权实现、调参、测试与验收，不等待 Codex 检查。UTF-8，保护用户改动，禁止提交/推送/PR/公网部署。

## 设计目标

有限地图可以维持生产循环。保留前期富集资源、快速采集和清巢奖励的价值；后期供给通过种植、深采、维修与回收延续，同时需要土地、劳动、燃料与运输。不要把地图资源定时整批刷回原状，也不要用随机宝箱或重新刷已清巢穴补资源。

游戏仍以清除八巢及残敌通关。基础消耗材料必须可续，战略奖励仍可稀缺；不是改成无限波次或无限地图。

## 资源分层

| 资源 | 早期来源 | 持续来源与代价 |
| --- | --- | --- |
| 木材 | 野外树木 | 复用树坑、树苗与再种植；等待生长、傀儡砍伐搬运、占用劳动力 |
| 纤维 | 草丛/已有采集点 | 草本或现有种植机制缓慢恢复；需实际采收，不直接发到基地 |
| 谷物/食品 | 起始少量口粮 | 本轮菜圃与食堂链；土地、劳动、木炭和物流 |
| 石料 | 地表富集石堆 | 原地耗尽后可建设慢速深采设施；燃料、活动魔力、人工与运输 |
| 铁矿 | 地表富矿及战利品 | 贫化矿点上的深矿；产量较低、成本较高，不能取代前期富矿 |
| 木炭/活动魔力 | 启动储备 | 木材转木炭、燃料供能；保持净正生产闭环与功率守恒 |
| 魔核、区域图纸、待招募奖励 | 清巢/既有明确奖励 | 保持既有有限来源和策略预算，不无限复制 |

DSH 先核实当前数据中的命名和已有再生规则，复用已有来源；上表不是允许建立第二份同类资源或库存。

## 采完地表资源，转向建设与深采

- 地表石料/铁矿耗尽是“富集层采完”，不是整片地质资源永远消失。留下可识别的矿址或贫矿标记，保存稳定 id、类型与位置，不能在原建筑/单位下面凭空刷矿。
- 玩家可在适合矿址建设采石设施或深矿井。矿址建设位置明确，不允许随处放置一个凭空造铁的机器；允许已有可用矿址提前规划，不必等最后一块铁用完才提示。
- 深采依靠真实燃料、活动魔力与傀儡工作；沿已有库存/作业/生产架构接入。产物必须实际搬运，不能隔空进入基地。耗材不足时停工并显示原因，恢复供给后可继续。
- 可用起始参数：每个深采周期约 45 秒、木炭 1，加对应活动魔力/劳动；石料产 4 或铁矿产 2。两类设施分工，不是一炉同时产两种。DSH 按实际作业及燃料周期调整最终数值，并记录吞吐与理由。
- 富矿采集效率明显高于深采；深采让后期可持续，但占用原本可用于采集、维修和运输的傀儡。提高矿产供给要付出更多设施与燃料，不免费恢复原地图产量。
- 采石设施的初始建设不能依赖石料，深矿的初始建设不能依赖铁矿；采用木材/纤维起步、木材/石料进阶等可闭环成本。不得以魔核作为持续开矿消耗或唯一恢复条件。
- 工具与装备优先维修、再利用；不能在矿耗尽且最后一把镐损坏后，要求先拿不存在的铁才能恢复采矿。基础工具的制作、修理或低效率手采路径必须可达。
- 不能为了维持供给把敌巢重新刷出来；已清路线安全、残敌处理、胜利条件保持。

## 材料回收缓冲失误

- 主动拆除玩家建造的普通建筑可回收部分真实投入，参考完好时约 60%；损毁残骸约 20%–30%。实际数值统一配置，并与生命/损毁情况对应。
- 回收量来自实际建造和已支付升级材料，不凭建筑等级猜一份资源。初始基地、免费生成对象、奖励对象不得返出没支付过的成本；不能拆基地绕过败局规则。
- 回收物落地、需要拾取/搬运；不能同时返库存又生成掉落。反复销毁、重载、重复事件都最多结算一次。
- 如既有系统已有拆除与退款，直接扩展同一规则并保留施工取消语义；不再建立另一套退款。
- 报废工具/武器可选用已有回收方式取回少量基础材料，但必须消费原实例，避免复制。优先完成建筑回收及工具维修闭环，不能因此扩大出复杂冶炼系统。

## 防止真正的资源软锁

种植本身的种苗和工具成本也要检查，不能宣称“树可以种”却在木材、种苗和斧头全部耗尽后没有任何启动路径。

需要保留极低效率的基础恢复路径：可徒手拾取/采集的枝条、碎石，或项目已有等价拾荒来源。若没有，设置极少量固定基础拾荒点，缓慢补充木材/石料、限制地上存量，产量不超过正规经营链的约十分之一，不生成铁矿、魔核或口粮。仍需傀儡实际取用，不是给基地无条件加钱。它用于重新做工具、恢复树坑或开采石点，不能供养完整防线。

补充计时走模拟时间，暂停时不产出；重载不能立刻再发一次，场上未捡走的物品不能无限积累。按补充事件处理，不每帧创建/销毁 GPU 资源。

资源管理失误仍可导致难以守住下一夜，但不得造成“基地和工人活着，却永远没有任何资源恢复操作”的隐藏死局。

## 界面与驱动力

资源点显示富集剩余量、贫化后的深采方式；生产界面显示真实燃料/材料缺口与产量，不把贫矿描述成永久不可再生。

有限时间优先开采富矿、清巢取得快速收益；长期经营转为种植、深矿和材料回收。玩家的选择是“继续扩张，还是投入可持续产能和运输”，而不是等资源条耗完。

## 必须验收

1. 从默认开局证明木材/木炭/供能启动链可达；不靠注入无限资源证明可玩。
2. 普通石堆和铁矿采完后，矿址、任务、视觉和库存状态正确；慢速设施可建立并实际取料、作业、出料和运输。
3. 燃料不足、断电、工具破损、背包/产物满、矿址被占、工人死亡、取消、重开和快照都不复制资源、不永久占任务。
4. 校验至少两个完整深采周期的材料、木炭、活动魔力与产量守恒，以及实际吞吐；富矿优势、深采可持续、燃料链净正三者同时成立。
5. 地表富集资源耗尽的测试场景仍能经营；最小资源/破损工具状态有基础恢复路径，正常经营不需要频繁依赖拾荒。
6. 拆除/损毁/升级建筑回收最多一次；免费与初始对象不产生无本资源；食物、工具维修和建筑维修的消耗均有长期供给。
7. 不恢复已清巢，不改变八巢+残敌判胜；再生/矿址/回收状态持久化，暂停规则一致，地图资源不会无限积累或逐帧扫描。
8. 相关语法、构建、旧回归、新规则和实际浏览器验收由 DSH 执行并修复。结果写入 docs/DSH_DEFENSE_SURVIVAL_RESULT.md 的“资源续航”部分，列最终参数、吞吐、证据与未解决问题；Codex 不复查代码。
