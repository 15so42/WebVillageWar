# 战斗特效制作准则

本项目的特效必须服务于俯视角 RTS 中的战斗辨识、卡牌反馈和阵地推进，不以堆叠粒子数量代替清晰的视觉设计。

## 粒子外观

- 能量、火焰、水流、烟雾、毒雾、治疗、命中火花等非实体粒子，默认必须具有中心到边缘的透明度衰减，禁止直接使用硬边纯色几何体充当粒子。
- 粒子的出现和消失都要有透明度变化；除极短促闪光外，不允许整颗粒子以固定不透明度突然出现或消失。
- 同一效果中的粒子应具有可控的大小、寿命、速度和方向分布，避免所有粒子完全一致。
- 发光核心负责高亮，外围粒子负责软边辉光与消散。`emissive` 不能替代透明度渐变；项目未启用全屏 Bloom 时，应使用软边材质、加法混合和局部高亮保证可见性。
- 普通攻击的粒子反馈应出现在伤害实际结算的击中位置，而不是攻击者手上。击中特效以短促向外爆发为主，尺寸和辉光保持克制，不能盖住单位轮廓与伤害数字。
- 击中特效必须使用投射物碰撞点或近战接触面，不能退化为单位脚下坐标。击中粒子的透明度应在较短半径内快速衰减，保留清晰核心，避免使用大范围柔化造成一团模糊光斑。
- 岩石、木屑、金属碎片、弹壳等有实体体积的碎片可以使用不透明几何体，但仍需通过大小、旋转、速度和明暗变化表现材质差异。

## 效果分层

一个主要战斗效果通常由以下层级中的两到四层组成：

1. 瞬时高亮核心：标明攻击或技能实际发生的帧。
2. 软边主体：表现能量、烟、火、水、毒等主要材质。
3. 消散粒子：沿运动方向或冲击方向离开主体，并随寿命缩小、淡出。
4. 地面反馈：范围圈、焦痕、水迹、尘土或阴影，用于交代作用范围和落点。

## 运动与材质

- 水系效果应至少包含透明主体和持续运动的流向信息；水球需要本体旋转、错速环流和绕球水滴，不能只显示静止蓝色球体。
- 火焰应有由亮到暗、由实到虚的空间渐变，并保持向上的流动趋势。
- 闪电不能依赖浏览器通常忽略的 `LineBasicMaterial.linewidth`；使用低边数分段实体、亮核与外层辉光建立稳定的世界空间宽度，亮核保留 HDR 颜色值并关闭 tone mapping。
- 雷云使用互相穿插、错速翻涌的低多边形云块形成连续体，内部闪电分批短促激荡；地面简影使用单个适度比例的椭圆，长短轴比控制在约 1.15–1.5，不能压得太扁或拉得过宽。
- 烟雾和毒雾应柔和叠加，避免多个硬边球体互相穿插。
- 爆炸使用极短促的 HDR 橙色低多边形核心标记爆发帧，视觉外扩必须依据实际伤害半径计算，不能让有范围伤害的爆炸看起来像不足一米的单点命中。
- 爆炸白烟由大小不一的白色低多边形烟块组成：向外爆发必须遵循“先快后慢”的减速曲线，快速建立爆炸范围；减速后转为缓慢向上蒸腾，在上升过程中持续缩小并淡出。不能匀速平移、突然停住或用持续扩张的实心圆盘代替爆炸主体。
- 单位死亡白烟需要按单位体型缩放，并使用大小、长宽比和旋转不同的半透明低多边形烟块形成瞬时爆发；不能用软贴图把烟糊成灰白光斑。烟块在生命周期内渐显、渐隐，并固定在主世界 `layer 0` 接受正常遮挡。
- 基地激光沿长度方向保持完整，不做首尾透明度衰减；只在光束两侧做边缘渐隐，消散点必须使用软边粒子。
- 训练与兵种专精的升级反馈使用多层软边环形光束绕单位旋转，并以短促星芒交代强化瞬间；默认处于主世界 `layer 0`、启用深度测试且不提高 `renderOrder`，允许单位和场景正常遮挡。

## 渲染与性能

- 优先复用 `src/art/vfxMaterials.js` 的共享软粒子纹理和材质工厂。
- 高频效果必须使用对象池；共享几何体、材质或纹理，避免每帧创建资源和触发 GC。
- 透明效果默认关闭深度写入。是否关闭深度测试应按可读性决定，不得让地形遮掉关键命中反馈，也不得无条件覆盖所有单位。
- 为移动端和大量单位同屏预留预算。先优化重复扫描、资源创建和过度绘制，再考虑降低更新频率。

## 验收清单

- 在实际游戏相机距离下能够看见效果，而不只是近距离检查模型。
- 粒子边缘是渐隐的，没有硬边纯色色块。
- 主体、消散和地面反馈在正确的战斗触发帧出现。
- 大小、速度、寿命和方向存在自然分布。
- 对象池回收后再次使用时，旋转、缩放、透明度和内部动画状态已正确重置。
