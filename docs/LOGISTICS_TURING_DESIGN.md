# 流水线逻辑门与清图目标

日期：2026-10-04。状态：生存关已接入。验收用脚本，不手操进游戏。

## 目标

玩家用木傀儡采集、用箱子之间的搬运组成流水线，做出附魔去强化战斗单位，用箭塔守住推进路线，直到毁掉地图上每一个刷怪点。

不做传送带。搬运仍由木傀儡执行。逻辑门只看箱子里有没有货，并决定哪一条运输线本拍能走。

## 为什么这样能搭出任意电路

门不绑定某一种材料。每路输入是一只箱子：

- 不指定种类时，箱子里有任何物品都算真。
- 指定了种类，就只数那一种。木头、石头、铁矿都可以，同一扇门的各路输入可以看不同物品。

| 机器 | 何时为通 |
| --- | --- |
| 与门 | 每一路输入都为真。没接输入时不通。 |
| 或门 | 任意一路为真。 |
| 非门 | 第一路为假（箱子是空的）。 |

运输线可以绑到一扇门上：门通时只走「通」，不通时只走「不通」。没绑门的线照常搬运。

箱子本身是记忆。或门同时看着「置位箱」和「保持箱」，门通时把一件货物搬进保持箱；之后清掉置位箱，或门仍然为通。与门再接一扇非门，就是与非。有反馈的与非门可以搭出锁存和更复杂的电路，所以这套门是泛用的，不是某一种矿石的计数器。

## 设备

与门、或门、非门都是可放置建筑，模型暂用箱子。打开门的面板，点选要接入的箱子。打开运输线面板，选择服从哪一扇门的通或不通。

木傀儡仍是工人。铁傀儡套件消耗魔力核心、深邃核心和铁矿，召唤后采集按 `workRate` 缩短工时，遇敌仍中断作业。

附魔台能把目录里的每一种附魔做成一块附魔石，成本都是一大笔岛上资源。力量附魔消耗 8 个魔石、40 个铁矿和 24 个木炭。魔石是怪物死亡掉落的，深邃核心仍然只给刷怪点和招募用。石头放进傀儡背包后给这具傀儡挂上同一种附魔；拿出来效果就消失。力量石每级物理攻击和魔法攻击各 +1.5。傀儡靠魔力运转，配方和巢穴掉落都不使用食物。

## 战斗、防守、胜利

- 胜利条件：全部刷怪点被毁，并且没有残余敌人。外圈四座巢穴和内圈一起挂上。
- 每个外圈巢穴带一个防守占位。把箭塔放进附近会吸到这个点。
- 流水线的战斗价值是产出附魔，再装备到战斗单位上。

## 地图

出生岛的四个刷怪点保持手摆。外圈四座巢穴和三片富铁矿按陆地坐标挂进生存关。富铁矿挖出来的是铁矿，给工具、建筑和附魔用。`planOuterRing` 仍是按半径出下一环的纯数据，不直接撒进海里。

## 验收

`scripts/test-logistics-turing.mjs`：

- 与门要每一路都有货才通，各路可以分别看木头和石头。
- 或门有一路有货就通；非门在箱子空着时通。
- 不指定种类时，任何物品都算有货。
- 或门加上「通的时候搬一件进保持箱」，清掉置位之后仍然为通。

- 木傀儡和铁傀儡正在采集时遇到贴脸的敌人会停手。
