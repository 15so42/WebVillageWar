# DSH 续修：自由建塔与默认开局体验

用户明确授权继续解决上一轮遗留问题，并纠正设计：玩家应自行决定箭塔位置，不应由预设箭塔位替玩家选址。Codex只写任务和转达结果，不审查代码、不重跑测试。你全权负责相关实现、真实交互验收、必要检查和报告。UTF-8。

## 1. 玩家自由选址（本轮明确新增要求）

上轮报告称 defenseSlot 是敌方进攻驻守点并承担箭塔吸附，后来标为「箭塔位」。玩家否定这种预设塔位引导。先理解实际引用，保留敌军必要的内部路线/集结逻辑，但它不能限定、吸附或暗示玩家建筑的固定位置。

- 去掉默认场景的预设箭塔圈和「箭塔位」标签；不要仅换名称或藏进帮助继续推荐这些点。
- 箭塔及同类防御建筑应由玩家在合法地形上自由选址。合法性继续由现有碰撞、地形、供能/建造范围及正常成本约束决定，不能只允许特定槽位、自动吸附到 enemy defenseSlot，或必须占住槽位才能有效防守。
- 移除对预设塔位的帮助文案及唯一槽位关联的奖励/放置依赖（若确有）；保持战斗、造价、供能、升级、维修与胜利规则兼容。不要用开放任意无效位置、免成本、穿模来实现自由。
- 若圈中某个确是实际危险预警，必须以真实危险事件触发和准确含义处理；不能继续常驻成「箭塔位」。保留必要的选中/放置预览，区分内部敌军路径点和玩家建筑。
- 真实 UI 验证至少两个不属于原槽位的合法位置放箭塔，选址不跳回槽位；确认非法位置仍被拒绝。塔能正常完成建造、供能、攻击、升级/维修相关回归按实际影响选择。

## 2. 收口上轮没有解决的开局接战

读取 docs/DSH_PLAYABILITY_RESULT.md 的遗留项，别把「约3秒唯一傀儡被敌军接战」称为已经完成的安全开局。用户要求初始傀儡能出门工作。本轮必须定位其真实触发条件并修复，不能只写建议或重复证明两分钟能运一点石料。

结合出生布局、敌军警戒/追击、傀儡默认遇敌策略、普通初始资源和采集路径调整最小必要项。初始工人优先经营，玩家仍可主动切换战斗模式；使用现有模式，不增加新系统。若默认改为避战，验证不被敌军追到基地死循环，尊重玩家后续显式指令。

开局应有足够可达资源和安全经营空间启动采集、运输、建造、供能和准备首夜防线。单纯改默认策略但敌军立即追入基地，不算修好。不得删除全部敌军或夜袭、无限资源、无敌、给免费军队或关闭战斗。保留扩张风险，首夜压力要有可操作的准备时间和可理解的反馈。
