## 体验与目标
现有内容已有采集、制造、物流、武装傀儡、清营地、八座内外巢穴、科技与附魔。缺口是玩家看不到选择的回报，中期只有拆巢数量、夜晚压力与泛化提示。补成：准备装备 → 选择一条远征线 → 拆内巢拿人手/招募资格/区域图纸 → 消耗采集物资研究独有能力 → 向外圈推进、彻底消除该路线夜袭 → 转投下一条路线。没有强制任务顺序或自动完成按钮。

## A. 四条远征路线（真实状态，不另维护一份完成进度）
纯数据入口放 gameData.js（SURVIVAL_EXPEDITIONS 或相当名称），纯规则模块 expedition.js，运行时/界面用独立 ExpeditionSystem/ExpeditionPanelUi（可合并小模块，不能往 Game.js 塞大段 HTML）。每条路线绑定既有内、外巢穴 id，展示当前目标、敌群、实际掉落数量、木傀儡奖励、待招募兵种和区域图纸。敌名/奖励必须读取真实点位/UNIT_DEFINITIONS/ITEM_DEFINITIONS，而非重复抄数字。状态：内巢未清 → 外巢可进攻 → 全线清除。外巢即使仍封印也能按现有规则被摧毁，UI必须忠于点位真实完成状态。
北：北岬巢穴 / 北岬盾巢（island-camp-north / island-outer-north）；西：西岭哨站 / 西北兽穴；东：东岬营地 / 东岬箭巢；南：南林深处 / 西南巨巢。每条写一句策略建议，明确不同敌型而非夸词。北为起步，西为采集续航，东为军械远程，南为重型目标与烧炭产能。
HUD加“远征”按钮打开可收起、非暂停的路线面板。每路线可“追踪”与“查看位置”（只移动相机，不给单位下指令；解除相机跟随并限制合法相机范围）。追踪只保存路线 id，后续目标自动从内巢换到外巢，清整线后显示已完成或转到尚未完成路线；保留玩家主动选择。当前目标显示收益理由；未选路线时现有提示逻辑保留但增强开局装备与入夜防线优先级。没有专用武器的唯一傀儡不应被目标句直接催去单挑两狼/两哥布林；根据真实装备状态提示合成/装备木棒或木刃（已有工具能战斗，文案不要说不能还手）。黑夜/入夜前60秒优先显示真实防线或燃料缺口，白天优先显示推进目标；撤销追踪可回到现有提示。B键交互规则维持当前“选中或悬停目标后开背包”。
面板手机可滚动，文字不溢出；关闭/Esc、暂停后继续、重新开始和destroy都必须工作，不抢地图手势。复用现有棕灰中世纪皮肤，不做紫蓝渐变或卡片套卡片。closed不构建DOM；状态/内容签名改变才更新；最多0.5秒采样已存在点位/库存集合，不每帧全量扫单位/敌人。

3) 东 / armsMaintenance / 军械保养：12铁+8炭+16纤维，己方移动战斗单位（含傀儡，排除建筑/基地/中立/敌人）攻击武器耐久消耗×0.8，延长远征；不改变采集工具扣耗规则/每次挥击速度/最大耐久，也不瞬间回满武器。
